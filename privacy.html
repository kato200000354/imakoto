いまコト プライバシーポリシー

制定日：2026年9月26日

「いまコト」（以下「本アプリ」）は、今話題の言葉を解説するアプリです。本アプリでの利用者の情報の取り扱いを、以下のとおり定めます。

1. 集める情報

本アプリは、名前・メールアドレス・電話番号・位置情報・連絡先などの個人情報を集めません。アカウント登録もありません。

2. 端末の中だけに保存する情報

次の情報は、利用者の端末（ブラウザの保存領域）の中だけに保存します。本アプリの運営者を含め、外部に送ることはありません。

  • お気に入りに保存した言葉
  • 見た言葉の履歴
  • 設定（興味のあるジャンル、通知時間の設定）

アプリを削除するか、ブラウザのサイトデータを消すと、これらの情報も消えます。

3. 通信について

本アプリは、最新の言葉のデータを受け取るため、GitHub Pages（GitHub, Inc. が運営）で公開しているファイルを読み込みます。この通信のとき、GitHub がアクセス記録（IPアドレスなど）を記録することがあります。取り扱いは GitHub のプライバシーステートメント に従います。

Android 版は Google Chrome などのブラウザの仕組みを使って表示します。ブラウザの取り扱いは、各ブラウザ提供者のプライバシーポリシーに従います。

4. 広告・分析ツール

本アプリは、広告を表示しません。利用状況を分析するツールも使っていません。

5. 掲載している情報について

言葉の解説は、公開されているニュースや記事を元に、AI（Claude）を使って毎日まとめています。各言葉のページに出典を載せていますが、内容が実際と異なる場合があります。

6. このポリシーの変更

内容を変更するときは、このページで知らせます。

7. お問い合わせ

本アプリについてのお問い合わせは、GitHub の Issues からお送りください。
